# Adlync – Smart Classified Ads & Marketplace

## 📌 Project Description
Adlync is a **web-based classified advertising platform** that enables users to post, browse,  
and search for various ads such as **vehicles, electronics, jobs, properties, and services**.  
The system provides a **secure and user-friendly interface** where buyers and sellers can  
efficiently connect, communicate, and manage listings with ease.

### ✨ Key Features
- **User Registration & Login** – Separate roles for Buyers & Sellers with email/phone verification.
- **Post an Ad** – Choose category, add title, description, price, images, and location.
- **Advanced Listing & Search** – Filter by category, price, location, and condition. Sort by latest or price.
- **Ad Details Page** – Image slideshow, seller contact info, and “Chat with Seller” or “Call Now”.
- **Admin Panel** – Approve/reject ads, manage users, and view, reject, approve reports.
- **Real-time Chat (Optional)** – Instant buyer–seller messaging using WebSocket.
- **Additional Enhancements**
    - Ad expiry & auto-renewal
    - Seller ratings & reviews
    - Saved ads / Wishlist
    - Progressive Web App (mobile friendly)
    - Smart search suggestions
    - Job section with CV/Resume upload
